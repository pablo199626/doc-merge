# Assets locales

- `documents/` contiene los documentos privados usados para validación local.
- `outputs/` contiene resultados generados que se ha decidido conservar.

El corpus local validado de generación de clases está en
`documents/New feature/`: `ANEXOS/` contiene históricos, `PDF/` los listados de
grupos y `TEMPLATES/ANEXO_TEMPLATE.docx` la plantilla vacía. Consulta
`docs/class-generation.md` antes de usarlo o cambiar sus contratos.

El contenido de ambas carpetas está ignorado por Git. No copies estos archivos
a `src/`, `tests/`, `legacy/` ni `release/`.
